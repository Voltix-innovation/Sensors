## 4. How to Use a Datasheet

When studying a sensor, check the following information:

1. Operating voltage and current consumption
2. Measurement range
3. Accuracy and resolution
4. Output type and communication interface
5. Pin configuration
6. Operating temperature range
7. Recommended circuit and safety limitations

**Important:** Specifications can vary between sensor models and manufacturers. Always consult the datasheet for the exact component you are studying. For safety-critical applications, use appropriately certified sensors and equipment.
