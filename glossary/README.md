
# Sensor Glossary

This glossary explains important technical terms used in sensor technology, measurement systems, electronics, and instrumentation.

## 1. Accuracy

Accuracy describes how close a measured value is to the true or accepted reference value.

**Example:** If the reference temperature is 25°C and a sensor reads 25.2°C, its reading is close to the reference.

## 2. Precision

Precision describes how close repeated measurements are to one another under the same conditions.

A sensor can produce consistent readings but still have an accuracy error.

## 3. Sensitivity

Sensitivity describes how much a sensor's output changes when the measured quantity changes.

**Example:** A temperature sensor's sensitivity may be expressed in millivolts per degree Celsius (mV/°C).

## 4. Resolution

Resolution is the smallest change in the measured quantity that a sensor or measurement system can distinguish.

## 5. Measuring Range

The measuring range is the interval between the minimum and maximum values a sensor is designed to measure.

**Example:** A sensor with a specified range of 0°C to 100°C is intended to measure temperatures within that interval.

## 6. Response Time

Response time describes how quickly a sensor responds to a change in the measured quantity. The exact definition may depend on the sensor specification.

## 7. Linearity

Linearity describes how closely a sensor's output follows a straight-line relationship with the measured quantity over a specified range.

## 8. Hysteresis

Hysteresis occurs when the sensor's output at a particular input depends on whether that input was approached from a higher or lower value.

## 9. Repeatability

Repeatability is the ability of a sensor or measurement system to produce similar results when the same quantity is measured repeatedly under the same conditions.

## 10. Calibration

Calibration is the process of comparing a sensor's readings with known reference values to determine its measurement error.

Calibration does not necessarily mean adjusting the sensor.

## 11. Drift

Drift is a gradual change in a sensor's output over time when the measured quantity remains constant.

## 12. Signal Conditioning

Signal conditioning involves processing a sensor's output to make it suitable for measurement or further use.

Examples include amplification, filtering, and signal conversion.

## 13. Transducer

A transducer converts one form of energy or physical quantity into another. Many sensors are transducers that convert a physical quantity into an electrical signal.

## 14. Static Characteristics

Static characteristics describe sensor performance under steady or slowly changing input conditions.

Examples include accuracy, sensitivity, linearity, and hysteresis.

## 15. Dynamic Characteristics

Dynamic characteristics describe how a sensor behaves when the measured quantity changes with time.

Examples include response time, time constant, and frequency response.
