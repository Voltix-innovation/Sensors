
# Infrared (IR) Sensors

## 1. Introduction

An infrared sensor detects infrared radiation or uses infrared light to identify nearby objects. Infrared radiation is electromagnetic radiation that is not normally visible to the human eye.

## 2. Working Principle

An active IR sensor generally contains an infrared emitter and a receiver. The emitter sends infrared light, and the receiver detects light reflected from an object.

A passive infrared (PIR) sensor detects changes in infrared radiation from objects, particularly people and animals.

## 3. Types of IR Sensors

- **Active IR Sensor:** Uses an emitter and receiver to detect reflected infrared light.
- **Passive Infrared (PIR) Sensor:** Detects changes in infrared radiation.
- **IR Temperature Sensor:** Measures thermal infrared radiation to estimate surface temperature.
- **IR Break-Beam Sensor:** Detects when an object interrupts an infrared beam.

## 4. Important Characteristics

- Detection range
- Response time
- Field of view
- Sensitivity
- Environmental interference

## 5. Applications

- Line-following robots
- Object detection
- Automatic doors
- Motion-activated lighting
- Remote-control receivers
- Security systems

## 6. Advantages

- Often compact and inexpensive.
- Suitable for non-contact detection.
- Useful in automation and robotics.
- Some types consume little power.

## 7. Limitations

- Sunlight and other IR sources may cause interference.
- Reflective surfaces and object colour can affect active IR detection.
- PIR sensors detect changes in infrared radiation rather than providing precise distance measurements.
- Detection performance depends on the sensor design and environment.

## 8. Examples

Common examples include IR obstacle detection modules, PIR motion sensors, and infrared break-beam sensors.
