
# Sensor Classification

## 1. Introduction

Sensors can be classified into different categories based on their working principle, output type, energy requirements, and method of measurement.

## 2. Classification Based on Output

### Analog Sensors

Analog sensors produce a continuously varying output signal related to the measured quantity.

Examples:
- LM35 temperature sensor
- LDR (Light Dependent Resistor)
- Analog pressure sensor

### Digital Sensors

Digital sensors provide data in a digital format, often through digital communication interfaces or discrete logic signals.

Examples:
- DS18B20 temperature sensor
- DHT22 temperature and humidity sensor
- Digital proximity sensor

## 3. Classification Based on Energy Requirements

### Active Sensors

In common sensor terminology, active sensors generate their own electrical response from the measured quantity or use an internally generated signal to perform sensing. The exact meaning depends on the sensor field.

Examples:
- Thermocouple
- Photovoltaic cell

### Passive Sensors

Passive sensors generally require external excitation or rely on changes in an electrical property to measure a quantity.

Examples:
- Thermistor
- Strain gauge
- RTD

## 4. Classification Based on Contact

### Contact Sensors

These sensors need physical contact with the object or medium being measured.

Examples:
- Contact temperature probe
- Contact displacement sensor

### Non-Contact Sensors

These sensors measure or detect a quantity without direct physical contact.

Examples:
- Infrared temperature sensor
- Ultrasonic distance sensor
- Radar sensor

## 5. Classification Based on Measured Quantity

- Temperature sensors
- Humidity sensors
- Pressure sensors
- Light sensors
- Motion sensors
- Gas sensors
- Proximity sensors
- Force sensors
- Magnetic sensors
- Sound sensors

## 6. Applications

Sensor classification helps engineers select appropriate sensors for robotics, industrial automation, environmental monitoring, healthcare, and consumer electronics.

## Conclusion

Understanding sensor classifications makes it easier to compare technologies and select a sensor for a particular measurement requirement.
