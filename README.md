# Sensor Knowledge Base

Welcome to the Sensor Knowledge Base, a learning resource for understanding different types of sensors used in electronics, robotics, automation, and embedded systems.

## What Is a Sensor?

A sensor is an electronic or physical device that detects changes in its surroundings and converts them into a measurable signal. This signal can be used to monitor conditions, detect objects, or control a system.

## Topics Covered

This repository provides basic knowledge about:

1. Temperature Sensors
2. Humidity Sensors
3. Ultrasonic Sensors
4. Infrared (IR) Sensors
5. Gas and Smoke Sensors
6. Motion Sensors
7. Light Sensors

## What You Will Learn

For each sensor, the documentation covers:

- Introduction and purpose
- Working principle
- Types of sensors
- Important characteristics
- Applications
- Advantages and limitations

## Applications of Sensors

Sensors are widely used in:

- Industrial automation
- Robotics
- Smart homes
- Healthcare equipment
- Environmental monitoring
- Automotive systems
- Safety and security systems

## Repository Structure

Each sensor category has its own folder containing a README file with its technical information and basic concepts.

## Purpose

The purpose of this repository is to build a structured knowledge base for students, beginners, and electronics enthusiasts interested in learning about sensors.
