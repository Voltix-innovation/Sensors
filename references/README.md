## 2. Sensor Datasheets

Datasheets provide information about sensor specifications, operating conditions, pin configurations, electrical characteristics, and limitations.

Examples of sensors to research:

- **LM35:** Analog temperature sensor
- **DS18B20:** Digital temperature sensor
- **DHT11 / DHT22:** Temperature and humidity sensors
- **HC-SR04:** Ultrasonic distance sensor
- **MQ-2:** Gas and smoke sensing module
- **LDR:** Light-dependent resistor
- **PIR sensor:** Passive infrared motion sensor
- **BH1750:** Digital ambient light sensor

For each component, search for the manufacturer's official datasheet. Confirm the exact model and manufacturer before relying on its specifications.

## 3. Important Information to Check

When reading a datasheet, look for:

- Operating voltage
- Measurement range
- Accuracy and sensitivity
- Response time
- Output type
- Pin configuration
- Operating temperature
- Calibration requirements
- Safety warnings and limitations

## 4. Recommended Learning Approach

1. Understand the physical quantity measured by the sensor.
2. Study its working principle.
3. Identify its type and output signal.
4. Read the official datasheet.
5. Compare its specifications with similar sensors.
6. Understand its applications and limitations.

## 5. Reference Guidelines

- Prefer manufacturer documentation and official datasheets.
- Verify specifications for the exact sensor model.
- Record the document title, manufacturer, and version when available.
- Do not treat educational sensor modules as certified safety equipment unless their certification and intended use have been verified.
